# Dataset reference

**Fruits Plant Leaf** — 291 images in 10 fruit-plant leaf classes, JPG/RGB images with CSV metadata. The dataset page lists the archive as 5.95 MB.

Source: https://doi.org/10.34740/KAGGLE/DSV/12928903
License listed by the source: CC BY-NC-SA 4.0.

Classes described by the source: Apple, Banana, Grapes, Guava, Jujube, Orange, Mango, Pineapple, Papaya, Watermelon.

Note: The dataset itself is not bundled in this project archive. Download it from the source and extract it into `dataset/`.
