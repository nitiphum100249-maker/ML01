# Face Image Dataset Processing and Classification

---

## 1. วัตถุประสงค์

วัตถุประสงค์หลักของโปรเจกต์มีดังนี้

1. เพื่อศึกษาโครงสร้างของ Dataset ที่ประกอบด้วยไฟล์ CSV และไฟล์รูปภาพ
2. เพื่อศึกษาเทคนิคการอ่านและจัดการข้อมูลด้วยภาษา Python
3. เพื่อเชื่อมโยงข้อมูลจากไฟล์ CSV เข้ากับรูปภาพใน Dataset
4. เพื่อศึกษาการตรวจสอบและทำความสะอาดข้อมูลก่อนนำไปใช้งาน
5. เพื่อเตรียมรูปภาพให้อยู่ในรูปแบบที่เหมาะสมสำหรับ Machine Learning หรือ Deep Learning
6. เพื่อแบ่งข้อมูลออกเป็นชุด Training, Validation และ Testing
7. เพื่อศึกษากระบวนการฝึกโมเดลและการประเมินผล
8. เพื่อวิเคราะห์ข้อผิดพลาดที่อาจเกิดขึ้นในระหว่างการทำงาน

---

## 2. เครื่องมือและเทคโนโลยีที่ใช้

โปรเจกต์สามารถพัฒนาโดยใช้เครื่องมือและ Library ต่อไปนี้

- **Python** — ภาษาหลักที่ใช้พัฒนาโปรแกรม
- **Pandas** — ใช้สำหรับอ่านและจัดการข้อมูลในไฟล์ CSV
- **NumPy** — ใช้สำหรับจัดการข้อมูลเชิงตัวเลขและ Array
- **Matplotlib** — ใช้สำหรับแสดงผลข้อมูลและรูปภาพ
- **OpenCV / Pillow** — ใช้สำหรับอ่านและประมวลผลรูปภาพ
- **Scikit-learn** — ใช้สำหรับแบ่ง Dataset และคำนวณค่าประเมินผล
- **TensorFlow / Keras หรือ PyTorch** — สามารถใช้สำหรับสร้างและฝึกโมเดล Deep Learning
- **Jupyter Notebook** — ใช้สำหรับทดลองและพัฒนาโค้ดแบบเป็นขั้นตอน

Library ที่ใช้งานจริงอาจแตกต่างกันขึ้นอยู่กับรูปแบบของโปรเจกต์

---

## 3. โครงสร้าง Dataset

ตัวอย่างโครงสร้าง Dataset ที่เหมาะสม

```text
lab1_faces/
│
├── train.csv
├── test.csv
│
├── Train/
│   ├── image_001.jpg
│   ├── image_002.jpg
│   ├── image_003.jpg
│   └── ...
│
└── Test/
    ├── image_001.jpg
    ├── image_002.jpg
    ├── image_003.jpg
    └── ...
```

ส่วนประกอบสำคัญ ได้แก่

- `train.csv` ใช้เก็บข้อมูลสำหรับชุด Training
- `test.csv` ใช้เก็บข้อมูลสำหรับชุด Testing
- `Train/` ใช้เก็บรูปภาพสำหรับการฝึกโมเดล
- `Test/` ใช้เก็บรูปภาพสำหรับการทดสอบโมเดล

ชื่อไฟล์และชื่อโฟลเดอร์สามารถแตกต่างจากตัวอย่างได้ แต่ Path ภายในโปรแกรมต้องตรงกับตำแหน่งจริงของไฟล์

---

## 4. หลักการทำงานของไฟล์ CSV

ไฟล์ CSV ใช้สำหรับเก็บ Metadata หรือข้อมูลกำกับของรูปภาพ เช่น

- ชื่อไฟล์รูปภาพ
- ID ของข้อมูล
- Label
- Class
- Category
- ค่าคุณลักษณะที่เกี่ยวข้องกับรูปภาพ

ตัวอย่างโครงสร้าง CSV

```csv
filename,label
image_001.jpg,0
image_002.jpg,1
image_003.jpg,0
```

โปรแกรมจะอ่านข้อมูลจาก CSV และใช้ชื่อไฟล์หรือ ID เพื่อค้นหารูปภาพที่สัมพันธ์กันภายใน Dataset

ดังนั้นข้อมูลใน CSV ต้องตรงกับชื่อไฟล์จริง มิฉะนั้นโปรแกรมอาจไม่สามารถโหลดรูปภาพได้

---

## 5. หลักการกำหนด Path

Path คือที่อยู่ของไฟล์หรือโฟลเดอร์ที่โปรแกรมต้องใช้ในการเข้าถึงข้อมูล

ตัวอย่าง

```text
lab1_faces/train.csv
lab1_faces/Train/
```

การกำหนด Path ต้องสอดคล้องกับตำแหน่งจริงของ Dataset ในเครื่องที่กำลังใช้งาน

ตัวอย่างเช่น หากย้าย Notebook ไปทำงานบนคอมพิวเตอร์เครื่องอื่น Path เดิมอาจไม่สามารถใช้งานได้ จึงควรตรวจสอบ Path ก่อนเริ่มประมวลผลทุกครั้ง

## 6. ขั้นตอนการทำงานของระบบ

ภาพรวมของ Workflow สามารถสรุปได้ดังนี้

```text
Dataset
   ↓

   ↓
ตรวจสอบโครงสร้างข้อมูล

เชื่อมโยง CSV กับไฟล์รูปภาพ
   ↓
ตรวจสอบข้อมูลที่หายไปหรือผิดพลาด
   ↓
ทำ Data Cleaning
   ↓

   ↓
แบ่งข้อมูล
   ↓
Training Model
   ↓
Validation
   ↓
Testing
   ↓
Evaluation
   ↓
วิเคราะห์และสรุปผล
```

## 7. การโหลดข้อมูล

ขั้นตอนแรกคือการอ่านข้อมูลจากไฟล์ CSV และตรวจสอบว่าไฟล์สามารถเข้าถึงได้

หลักการสำคัญที่ควรตรวจสอบ ได้แก่

- ไฟล์ CSV มีอยู่จริงหรือไม่
- ชื่อไฟล์ถูกต้องหรือไม่
- ตำแหน่ง Path ถูกต้องหรือไม่
- จำนวนข้อมูลทั้งหมด
- ชื่อ Column
- ประเภทข้อมูลในแต่ละ Column
- Missing Value
- ข้อมูลซ้ำ

การตรวจสอบเบื้องต้นช่วยลดข้อผิดพลาดในขั้นตอนต่อไป

## 8. Data Cleaning

Data Cleaning คือกระบวนการทำความสะอาดข้อมูลก่อนนำไปใช้งาน

ตัวอย่างการตรวจสอบ ได้แก่

- ลบข้อมูลที่ซ้ำกัน
- ตรวจสอบข้อมูลที่ไม่มี Label
- ตรวจสอบชื่อไฟล์ที่ไม่ตรงกับรูปภาพจริง
- ตรวจสอบไฟล์รูปภาพที่เสียหาย
- ตรวจสอบข้อมูลที่อ่านไม่ได้
- ตรวจสอบค่าที่ผิดปกติ
- จัดรูปแบบ Label ให้เป็นมาตรฐานเดียวกัน

Dataset ที่มีความถูกต้องและมีคุณภาพจะช่วยให้โมเดลเรียนรู้ได้ดีขึ้น

---

## 9. Image Preprocessing

ก่อนนำรูปภาพเข้าสู่โมเดล ควรเตรียมรูปภาพให้อยู่ในรูปแบบเดียวกัน

### 9.1 Resize

ปรับขนาดรูปภาพให้มีขนาดเท่ากัน เช่น

```text
224 × 224 pixels
```

หรือขนาดอื่นตาม Input ของโมเดล

### 9.2 Normalize

ค่าของ Pixel ในรูปภาพทั่วไปอยู่ในช่วง

```text
0 - 255
```

สามารถ Normalize ให้อยู่ในช่วง

```text
0 - 1
```

เพื่อให้โมเดลสามารถเรียนรู้ได้ง่ายและมีความเสถียรมากขึ้น

### 9.3 Color Conversion

รูปภาพอาจต้องถูกแปลงรูปแบบสี เช่น

```text
BGR → RGB
RGB → Grayscale
```

ขึ้นอยู่กับ Library และรูปแบบของโมเดลที่ใช้งาน

### 9.4 Face Region

ในกรณีที่งานเน้นใบหน้าโดยเฉพาะ อาจมีการตรวจจับบริเวณใบหน้าก่อนนำเข้าสู่โมเดล เพื่อช่วยลดข้อมูลพื้นหลังที่ไม่เกี่ยวข้อง

---

## 10. Data Augmentation

Data Augmentation เป็นเทคนิคเพิ่มความหลากหลายของ Dataset โดยสร้างรูปแบบใหม่จากภาพเดิม

ตัวอย่างเช่น

- หมุนรูปภาพ
- Flip รูปภาพ
- Zoom
- Crop
- ปรับความสว่าง
- ปรับ Contrast
- เลื่อนตำแหน่งภาพ
- ปรับมุมเล็กน้อย

ข้อดีของ Data Augmentation คือช่วยให้โมเดลมีโอกาสพบข้อมูลที่หลากหลายมากขึ้น และช่วยลดปัญหา Overfitting

อย่างไรก็ตาม การ Augment ต้องไม่เปลี่ยนความหมายของข้อมูลเดิม

---

## 11. การแบ่ง Dataset

โดยทั่วไป Dataset สามารถแบ่งออกเป็น 3 ส่วน

### Training Set

ใช้สำหรับให้โมเดลเรียนรู้ข้อมูลและปรับค่าพารามิเตอร์

### Validation Set

ใช้ตรวจสอบประสิทธิภาพของโมเดลในระหว่างการ Training

### Testing Set

ใช้สำหรับประเมินผลโมเดลหลังจาก Training เสร็จแล้ว โดยควรเป็นข้อมูลที่โมเดลไม่เคยใช้ในการฝึก

ตัวอย่างสัดส่วน

```text
Training    70%
Validation  15%
Testing     15%
```

หรือ

```text
Training    80%
Testing     20%
```

สัดส่วนที่เหมาะสมขึ้นอยู่กับจำนวนข้อมูลและวัตถุประสงค์ของการทดลอง

---

## 12. การฝึกโมเดล

ในขั้นตอน Training โมเดลจะรับข้อมูลจาก Training Set และเรียนรู้ความสัมพันธ์ระหว่างรูปภาพกับ Label

โดยทั่วไปกระบวนการฝึกจะเกิดขึ้นหลายรอบ เรียกว่า **Epoch**

ตัวอย่าง

```text
Epoch 1
Epoch 2
Epoch 3
...
Epoch 20
```

ในแต่ละ Epoch โมเดลจะพยายามลดค่าความผิดพลาดหรือ Loss และปรับค่าภายในโมเดลให้สามารถทำนายข้อมูลได้ดีขึ้น

---

## 13. Batch Size

Batch Size คือจำนวนข้อมูลที่นำเข้าสู่โมเดลในแต่ละรอบย่อย

ตัวอย่าง

```text
16
32
64
128
```

Batch Size ที่เหมาะสมขึ้นอยู่กับ

- จำนวนข้อมูล
- ขนาดของรูปภาพ
- ขนาดของโมเดล
- RAM
- GPU Memory

หาก Batch Size ใหญ่เกินไปอาจทำให้หน่วยความจำไม่เพียงพอ

---

## 14. Learning Rate

Learning Rate เป็นค่าที่กำหนดขนาดของการปรับค่าพารามิเตอร์ของโมเดล

หาก Learning Rate สูงเกินไป โมเดลอาจเรียนรู้ไม่เสถียร

หาก Learning Rate ต่ำเกินไป โมเดลอาจเรียนรู้ช้าและใช้เวลานาน

จึงควรทดลองเลือกค่าที่เหมาะสมกับ Dataset และโมเดล

---

## 15. การประเมินผลโมเดล

หลังจาก Training แล้วควรนำโมเดลมาประเมินผลด้วยข้อมูล Testing Set

ค่าที่นิยมใช้ในการประเมิน ได้แก่

### Accuracy

วัดสัดส่วนของจำนวนข้อมูลที่โมเดลทำนายถูกต้องเมื่อเทียบกับข้อมูลทั้งหมด

### Precision

วัดความแม่นยำของตัวอย่างที่โมเดลทำนายว่าเป็น Class ใด Class หนึ่ง

### Recall

วัดความสามารถในการค้นหาตัวอย่างของ Class ที่ต้องการได้ครบถ้วน

### F1-Score

เป็นค่าที่ใช้พิจารณาร่วมกันระหว่าง Precision และ Recall

---

## 16. Confusion Matrix

Confusion Matrix เป็นเครื่องมือที่ใช้วิเคราะห์ผลการจำแนกข้อมูลของโมเดล

ช่วยให้สามารถตรวจสอบได้ว่าโมเดล

- ทำนาย Class ใดได้ถูกต้อง
- สับสนระหว่าง Class ใด
- มี False Positive มากหรือไม่
- มี False Negative มากหรือไม่

การดูเพียง Accuracy อย่างเดียวอาจไม่เพียงพอ โดยเฉพาะ Dataset ที่จำนวนข้อมูลแต่ละ Class ไม่สมดุล

---

## 17. Overfitting

Overfitting เกิดขึ้นเมื่อโมเดลสามารถจดจำ Training Set ได้ดีมาก แต่ไม่สามารถทำนายข้อมูลใหม่ได้ดี

สาเหตุที่พบได้บ่อย ได้แก่

- Dataset มีจำนวนน้อย
- โมเดลซับซ้อนเกินไป
- Training เป็นจำนวน Epoch มากเกินไป
- Dataset ไม่มีความหลากหลาย

แนวทางลด Overfitting เช่น

- Data Augmentation
- Dropout
- Early Stopping
- เพิ่มจำนวนข้อมูล
- ลดความซับซ้อนของโมเดล

---

## 18. Underfitting

Underfitting เกิดขึ้นเมื่อโมเดลยังไม่สามารถเรียนรู้รูปแบบของข้อมูลได้เพียงพอ

ลักษณะที่อาจพบ ได้แก่

- Training Accuracy ต่ำ
- Validation Accuracy ต่ำ
- Loss ยังสูง
- ผลการทำนายไม่ดีทั้งข้อมูลเก่าและข้อมูลใหม่

สาเหตุอาจเกิดจากโมเดลง่ายเกินไป จำนวน Epoch น้อยเกินไป หรือค่าพารามิเตอร์ไม่เหมาะสม

---

## 19. ข้อผิดพลาดที่อาจพบ

### FileNotFoundError

ข้อผิดพลาดนี้เกิดเมื่อโปรแกรมไม่พบไฟล์หรือโฟลเดอร์ใน Path ที่กำหนด

สาเหตุที่พบบ่อย

- Path ไม่ถูกต้อง
- ชื่อไฟล์ผิด
- ชื่อโฟลเดอร์ผิด
- Dataset ถูกย้ายตำแหน่ง
- ไฟล์ถูกลบ
- ใช้ Path จากคอมพิวเตอร์หรือ Environment อื่น

แนวทางตรวจสอบ

1. ตรวจสอบตำแหน่ง Dataset
2. ตรวจสอบชื่อไฟล์
3. ตรวจสอบชื่อโฟลเดอร์
4. ตรวจสอบ Working Directory ของ Notebook
5. ตรวจสอบว่าไฟล์ CSV สามารถเปิดได้จริง

---

### ไม่พบรูปภาพ

อาจเกิดจากชื่อรูปภาพใน CSV ไม่ตรงกับไฟล์จริง

ควรตรวจสอบ

- นามสกุลไฟล์ เช่น `.jpg`, `.jpeg`, `.png`
- ตัวอักษรพิมพ์ใหญ่และพิมพ์เล็ก
- ชื่อไฟล์ใน CSV
- Path ของโฟลเดอร์รูปภาพ

---

### รูปภาพเสียหรืออ่านไม่ได้

หากไฟล์รูปภาพเสียหาย Library อาจไม่สามารถเปิดไฟล์ได้

ควรตรวจสอบรูปภาพก่อนนำเข้าสู่กระบวนการ Training

---

### Memory ไม่เพียงพอ

หากโหลดรูปภาพจำนวนมากหรือใช้ Batch Size สูง อาจทำให้ RAM หรือ GPU Memory ไม่เพียงพอ

แนวทางแก้ไข

- ลด Batch Size
- ลดขนาดรูปภาพ
- โหลดข้อมูลเป็น Batch
- ไม่โหลด Dataset ทั้งหมดเข้าสู่ RAM พร้อมกัน

---

## 20. แนวทางปรับปรุงประสิทธิภาพ

สามารถพัฒนาโปรเจกต์เพิ่มเติมได้หลายแนวทาง เช่น

- เพิ่มจำนวน Dataset
- เพิ่มความหลากหลายของรูปภาพ
- ปรับ Image Preprocessing
- ทดลองโมเดลหลายรูปแบบ
- ทดลอง Learning Rate หลายค่า
- ปรับ Batch Size
- ใช้ Data Augmentation
- ใช้ Transfer Learning
- วิเคราะห์ Confusion Matrix
- ตรวจสอบความสมดุลของ Class
- เพิ่ม Early Stopping
- เพิ่มระบบบันทึกโมเดลที่มีผลดีที่สุด

---

## 21. ข้อควรระวังเกี่ยวกับ Dataset ใบหน้า

เนื่องจากข้อมูลใบหน้าเป็นข้อมูลที่มีความละเอียดอ่อน จึงควรใช้ Dataset อย่างเหมาะสมและคำนึงถึงความเป็นส่วนตัวของเจ้าของข้อมูล

ควรหลีกเลี่ยงการเผยแพร่ข้อมูลส่วนบุคคลโดยไม่ได้รับอนุญาต และควรใช้ Dataset ตามวัตถุประสงค์ของการศึกษาและตามเงื่อนไขของแหล่งข้อมูล

---

## 22. ผลลัพธ์ที่คาดหวัง

หลังจากดำเนินการตามขั้นตอนของโปรเจกต์ ผู้จัดทำควรสามารถ

- อ่านข้อมูลจากไฟล์ CSV ได้
- เชื่อมโยงข้อมูลกับไฟล์รูปภาพได้ถูกต้อง
- ตรวจสอบและจัดการข้อมูลที่ผิดพลาดได้
- เตรียมรูปภาพก่อนเข้าสู่โมเดลได้
- แบ่ง Dataset อย่างเหมาะสม
- ฝึกโมเดลด้วย Training Set
- ทดสอบโมเดลด้วยข้อมูลใหม่
- ประเมินผลโมเดลด้วย Metric ที่เหมาะสม
- วิเคราะห์จุดอ่อนและแนวทางปรับปรุงโมเดลได้

---

## 23. สรุป

โปรเจกต์นี้เป็นการศึกษา Workflow ของการประมวลผลชุดข้อมูลรูปภาพใบหน้า ตั้งแต่การอ่านข้อมูลจากไฟล์ CSV การตรวจสอบความถูกต้องของ Dataset การทำ Data Cleaning การเตรียมรูปภาพ การแบ่งข้อมูล การ Training และการประเมินผลโมเดล

สิ่งสำคัญไม่ได้อยู่เฉพาะขั้นตอนการสร้างโมเดลเท่านั้น แต่รวมถึงการเตรียม Dataset ให้ถูกต้อง เพราะข้อมูลที่ไม่สมบูรณ์หรือ Path ที่กำหนดไม่ถูกต้องสามารถทำให้โปรแกรมไม่สามารถทำงานต่อได้

การตรวจสอบ Dataset อย่างเป็นระบบจึงเป็นขั้นตอนสำคัญที่ช่วยลดข้อผิดพลาด เพิ่มความน่าเชื่อถือของผลการทดลอง และทำให้กระบวนการพัฒนา Machine Learning หรือ Deep Learning มีประสิทธิภาพมากขึ้น
